Task Context Card(TCC)는 재개 비용을 낮추려고 만든 비-SSOT 캐시였습니다. 재개에 쓰였다는 직접 증거를 찾지 못했고, 훅이 설치된 저장소에서도 카드 절반 이상이 빈 채였습니다. 그래서 감지 장치를 붙이는 대신 장치를 뺐습니다. 현재 단계는 이제 plan에서 파생됩니다.

효과
매 세션 로드되는 프로젝트 지시가 17,256 B에서 15,832 B로 1,424 B 줄었습니다. 상한까지 여유가 244 B였습니다.
