매 세션 로드되는 지시에서
2 KB를 덜어냈습니다

0.32.3은 0.32.2가 남긴 문제를 고칩니다. 그 릴리스는 AGENTS.md에 1,397 B를 더해 eager 계층 예산(24 KiB)을 64 B 넘긴 채 태그까지 나갔고, 발행 뒤 doctor로 드러났습니다. 남은 여유는 275 B였습니다 — 규칙을 한 문단 더 쓸 때마다 예산과 협상해야 하는 상태였고, 협상 결과가 "규칙을 덜 쓰는 것"이면 문서가 아니라 계약이 손해를 봅니다. 절차 본문을 lazy 정본으로 옮겨 여유를 2,230 B로 되돌립니다. 규칙은 한 줄도 사라지지 않습니다.

여유 275 B는 규칙을 못 쓰게 만듭니다

eager 계층은 매 세션 무조건 로드되는 지시입니다 — 필요할 때만 읽는 lazy 정본(커맨드 문서·스킬·가드 메시지)과 다릅니다. 비대는 전 세션 비용입니다.

판별 기준은 새로 만들지 않았습니다. 선행 작업(instruction-structure)이 정의한 것을 재적용했습니다 — 트리거를 컨텍스트 없이 인지할 수 있는가. 인지할 수 있으면 절차는 lazy로, eager에는 트리거만 남깁니다. 상황 인식형 규칙(CLAUDE.md §5-A 복잡도 게이트, JIT retrieval)은 트리거가 상황 자체라 이전 대상이 아닙니다.

옮긴 것과 도착지 — 삭제가 아니라 이전입니다

항목마다 도착지를 grep으로 확인했습니다. 옮겼다고 기억하는 것과 도착지가 존재하는 것은 다릅니다 — 실제로 하나는 도착지 없이 사라질 뻔했습니다.

도달성이 이전의 상한을 정합니다. Codex는 commands/에 도달합니다 — skill mirror가 ../../commands/<name>.md를 읽으라고 지시하기 때문입니다. 도달하지 못하는 것은 Cursor뿐이고, Cursor는 명령을 실행하지 않지만 plan.md는 편집합니다. 그래서 plan을 닫는 규칙은 eager에 남습니다 — 다이어그램 단계를 지우지 말고 사유를 붙여 닫으라는 것, artifact에 한 줄 남기라는 것.

여유는 다시 사라집니다 — 그래서 가드를 둘 세웠습니다

이 릴리스의 감축량보다 중요한 것은 다시 좁아지지 않게 하는 것입니다. tests/agent-files.test.mjs에 상한 가드 둘이 생깁니다.
