Changed

권한은 템플릿이 아니라 stackPermissions가 만듭니다

변경
템플릿 templates/.claude/settings.json은 pm·스택 무관 항목만 남깁니다(allow 15→6, deny 8→6). 새 순수 함수 stackPermissions(profile, { stackId })(src/settings-permissions.mjs)가 스택 프로필에서 pm 의존 항목과 RN 항목을 만들고, planChanges가 그것을 템플릿에 합성한 뒤 기존 settings와 deep-merge합니다. RN 판정은 excludesRnRules와 같은 입력(명시 --stack > 감지값)입니다.
왜
0.23.0이 RN 전용 rules를 스택으로 게이트했을 때 권한 목록은 그대로 두어, 같은 판정을 두 표면이 다르게 내리고 있었습니다. 고정 목록은 pnpm 사용자에게만 맞고 나머지에게는 소음이었습니다 — 허용되지 않은 명령은 매번 승인 프롬프트로 돌아옵니다.
그래서
pm 게이트와 RN 게이트는 독립 블록입니다. package.json 없는 디렉터리에 --stack expo를 강제해도 네이티브 deny 2종은 들어갑니다 — 첫 판은 pm early return이 RN 게이트를 삼켰고 외부 리뷰가 그것을 잡았습니다(아래). 매트릭스는 tests/settings-permissions.test.mjs 16건으로 고정됐습니다.
알려진 한계: 기존 settings와의 병합은 합집합이라 이미 스캐폴드된 프로젝트의 옛 pnpm … 항목은 남습니다(무해하지만 낡음). 필요하면 손으로 지우십시오 — 자동 제거는 별도 결정으로 둡니다. npx expo install *는 pm 무관 고정이라 yarn expo install을 쓰는 팀은 그 항목을 직접 추가해야 합니다.

Fixed

결정 로그 검사 목록이 D-log와 함께 움직입니다

변경
checkDecisionLog의 DECISION_HEADINGS에 ## D6·## D7을 더했습니다. 파일 부재 메시지가 나열하는 절 ID는 같은 상수에서 파생합니다. docs/decisions.md의 상류 출처 목록도 D7까지 적습니다.
왜
D6(2026-08-26)·D7(2026-09-03)이 템플릿 D-log와 AGENTS.md 코어 요약에 들어간 뒤에도 검사 목록은 갱신되지 않았습니다. 스캐폴드는 기존 docs/decisions.md를 덮어쓰지 않으므로 doctor 경고가 유일한 신호인데, 그 신호가 꺼져 있었습니다. 템플릿↔검사 계약 테스트는 “검사 목록 ⊆ 템플릿”만 봐서 템플릿이 자라는 드리프트를 통과시켰습니다.
그래서
템플릿의 모든 ## D<n> 헤딩과 검사 목록을 집합 동등으로 대조하는 가드 테스트가 들어갔습니다(D7을 임시로 빼서 실패하는 것을 확인). D6·D7 이전에 스캐폴드된 프로젝트는 다음 doctor에서 warn 1건을 새로 봅니다 — templates/docs/decisions.md에서 두 절을 가져오면 됩니다.

이 릴리스가 남기는 것

한 함수 안의 두 게이트는 순서가 곧 계약이다

pm 게이트의 early return이 RN 게이트를 삼켜, package.json 없는 --stack expo에서 네이티브 deny가 사라졌습니다. 독립인 조건은 독립 블록으로 씁니다. 그리고 배선 뒤에 쓴 통합 테스트는 배선을 잠시 꺼서 실제로 실패하는지 봅니다 — 6건 중 4건이 실패해야 변별력이 증명됩니다.

“검사 목록 ⊆ 정본”은 정본이 자라는 드리프트를 못 잡는다

doctor의 D-log 검사와 템플릿의 계약 테스트는 검사 목록이 템플릿에 포함되는지만 봤습니다. 템플릿에 D6·D7이 더해져도 통과했고, 그래서 그 뒤 몇 릴리스 동안 아무도 몰랐습니다. 목록과 정본이 함께 움직여야 하는 계약은 포함이 아니라 집합 동등으로 고정합니다.

위임한 조사에는 코드 시점을 박는다

외부 플레이북과 하네스를 비교한 분석은 삭제된 워크트리의 0.23.1 코드를 봤고, 인계받은 세션이 main과 대조하니 다섯 군데가 달랐습니다(권고 하나는 이미 이 릴리스에서 해결됨). 조사 결과에는 커밋 sha가 붙어야 하고, 인계받는 쪽은 파일을 믿지 않고 실제 상태와 대조합니다 — 원 세션이 나중에 보낸 정정도 같은 결론이었습니다.
