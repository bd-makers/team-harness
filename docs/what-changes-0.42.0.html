바뀐 것

Added · CLI

list --remote

이전
list는 체크아웃한 브랜치의 task만 봤습니다. 2026-09-08에는 열린 task가 든 브랜치를 "머지됨"으로 오인해 지울 뻔했습니다.
지금
--remote를 주면 로컬 목록 뒤에 branch-only (origin, 마지막 fetch 기준): 절이 붙습니다. 기본 브랜치의 조상인 브랜치는 건너뛰고, 로컬·기본 브랜치에 이미 있는 task는 뺍니다. --area는 그 브랜치의 meta로 거릅니다.
계약
fetch하지 않습니다 — 로컬 refs/remotes/origin/*만 읽습니다. 지워진 원격 브랜치를 빼려면 먼저 git fetch --prune. git·origin이 없으면 한 줄 안내, exit code는 그대로입니다.
Fixed · CLI

경로 경계 세 곳

active 포인터
손으로 고친 .harness/active.json의 user·task가 docs/<user>/<task>/ 한 세그먼트가 아니면 활성 task 없음으로 보고 stderr에 경고합니다. doctor도 같은 판독을 씁니다.
task 이름
.·..은 문자 규칙을 통과해 빈 docs/에 docs/..-spec.md 등을 만들었습니다. 이제 쓰기 전에 거부합니다.
원격 ref
done-on-main 판정이 git show origin/main:…을 써서 같은 이름의 로컬 브랜치를 읽을 수 있었습니다. 이제 refs/remotes/origin/main으로 읽습니다.
Decision · D10

CLAUDE.md 유지

배경
Claude Code 2.1.277부터 AGENTS.md를 네이티브로 읽지만 기본은 fallback(CLAUDE.md가 없을 때만)이고 사용자 설정·원격 플래그에 묶여 있습니다.
결정
CLAUDE.md(@AGENTS.md import) 구조를 유지합니다. 재검토 조건과 그때의 opt-in 경로는 docs/decisions.md D10에 있습니다.
