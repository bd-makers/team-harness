doctor가 실행되지 않는 CLI를
옛 CLI로 오진하지 않습니다

doctor의 global CLI version drift 검사는 harness-team --version이 0 아닌 exit로 끝나면 모두 "0.15.1 이전 CLI"로 단정했습니다. mise·nvm·asdf shim이 Node 전환 뒤 실행에 실패하는 경우에도 clone git pull을 처방해, 고쳐도 경고가 사라지지 않았습니다. 0.58.3은 옛 CLI와 실행 실패를 구분하고, 실행 실패에는 원인 첫 줄과 다시 설치하는 명령을 보여 줍니다.

실행 실패

무엇
그 밖의 0 아닌 exit(127 포함)는 "실행되지 않음 (exit N: 첫 줄)"로 보고하고, 활성 Node에서 npm i -g "<clone>"로 다시 설치·연결하라고 처방합니다. --json next_actions도 같은 명령이며, plugin-dev 모드에서도 경고합니다.
