바뀐 것

Added · doctor

낡은 관리 절 경고

이전
관리 절이 템플릿보다 낡아도 doctor는 조용했습니다. 2026-09-26 deep-math는 protocol 절이 0.42.0 문구인 채 경고가 없었습니다.
지금
관리 절 N개가 최신 템플릿보다 낡음: AGENTS.md#protocol …을 내고 nextActions에 harness-team init을 넣습니다.
판정
init과 같은 병합(mergeMarkdown)을 메모리에서 돌려 init이 실제로 바꿀 절만 셉니다. 사용자가 편집한 절, .harness/render-state.json이 없는 설치본, symlink, 마커가 깨진 파일은 보고하지 않습니다.
Fixed · 문서

관리 절은 init으로 받는다

이전
harness-migrate 설명이 migrate를 "템플릿 수정이 도달하는 유일한 경로"라 적었습니다 — 훅·스킬·규칙 같은 파일 단위 설치본에만 참입니다. 0.42.1 릴리스 노트가 이 문장을 믿고 "소비자는 migrate로 받는다"고 썼습니다.
지금
migrate·init 문서가 "관리 절은 init만 갱신한다"를 명시합니다. 발행된 what-changes-0.42.1.html은 그 시점의 기록이라 고치지 않았습니다.

소비자가 할 일

Do

플러그인 갱신 → doctor

왜
templates/는 불변입니다. 새 경고는 플러그인 코드에 있습니다.
어떻게
/plugin marketplace update(또는 clone에서 git pull) 뒤 harness-team doctor. 새 경고가 뜨면 harness-team init — 0.42.1을 migrate만으로 받았다면 여기서 protocol 절이 잡힙니다.
Check

init --stack으로 설치했다면

무엇
강제한 스택은 저장되지 않아 stack 절이 낡은 것으로 보일 수 있습니다.
참고
플래그 없는 init도 감지 스택으로 같은 렌더를 하므로 경고는 init 동작과 일치합니다. 강제 스택을 유지하려면 init --stack <id>로 다시 실행하세요.
