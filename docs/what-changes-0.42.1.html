바뀐 것

Fixed · CLI

추론 base = refs/remotes/origin/<branch>

이전
기본 브랜치 후보를 짧은 origin/main으로 검증·사용했습니다. refs/heads/origin/main 로컬 브랜치가 있으면 git이 그쪽을 먼저 풀어 diff 범위가 틀어지거나 비었고, 그 base가 프롬프트로 리뷰어에게도 넘어갔습니다.
지금
추론한 base는 전체 이름으로 판정·diff·프롬프트에 같은 값이 쓰입니다. resolveDefaultRef의 폴백 검증도 전체 ref로 합니다.
표시 변화
scope·review 출력의 추론 base가 refs/remotes/origin/main처럼 나옵니다.
Changed · 규범

handoff는 다음 커밋에 담는다

이전
훅이 커밋 뒤에 handoff 2파일을 써서 트리가 dirty로 남았고, 세션이 매 작업 커밋 직후 그것만 담는 커밋을 붙였습니다 — 2026-09-20~25 이력 98커밋 중 23개.
지금
handoff 변경은 다음 작업 커밋(또는 ship 문서 커밋)에 함께 담습니다. dirty handoff는 done 가드가 무시합니다.
예외
푸시·브랜치 전환·워크트리 정리 직전에 남은 변경이 handoff뿐이면 그때 단독 커밋 하나 — 보통 PR/MR당 한 번이며 상한은 없습니다. 정본은 commands/harness-task.md.
