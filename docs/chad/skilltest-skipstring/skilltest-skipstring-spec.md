# skilltest-skipstring — Spec

## 목적 / 요구사항

`tests/sim/skilltest.mjs` 토큰화기의 `skipString`이 백틱이 아닌 따옴표
문자열에서 raw 개행을 넘지 않게 해, 줄별 JSX 산문의 아포스트로피가
본문 마커와 `it()` 선언을 가짜 문자열로 마스킹하는 두 발현을 같이 제거한다.

완료 기준:
- 본문 마커 마스킹과 선언 스캔 조용한 FAIL의 회귀 테스트가 수정 전 FAIL, 수정 후 PASS.
- 개행 수정 후 선언부 fail-safe(A2) 필요성을 실측 판정.
- 기존 채점 대상 파일 전수 비교 및 변경 파일별 정당성 판정.
- `node tests/sim/skilltest.mjs selftest`, `npm run test` 통과.

## 설계 / 접근

`skipString` 자체에 개행 경계를 추가한다. 단, 백틱 템플릿 리터럴은 개행이
합법이므로 기존처럼 닫는 백틱까지 스캔한다. 기존 사후 우회인
`hasMisparsedString` 필요성도 같이 재평가한다. 채점 규칙·출력은 변경하지 않는다.

## Ontology
*이 task가 다루는 핵심 개념의 정의. "X가 정확히 뭔가?"에 답한다.*

- **문자열 경계**: `'`/`"` 리터럴은 escape된 줄 이음을 제외하고 raw 개행을
  포함할 수 없으므로, 토큰화 복구 시 개행을 스팬 상한으로 본다.
- **템플릿 경계**: 백틱 리터럴은 raw 개행이 합법이므로 오직 닫는 백틱이
  스팬 상한이다.
- **A2 선언부 안전장치**: 선언 개수가 0인 경우 오파싱을 별도 탐지하는
  fail-safe. 근본 개행 경계로 선언 누락이 재현되지 않으면 중복 계층이므로 넣지 않는다.
