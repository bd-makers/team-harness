Claude Plugin vs Codex Plugin

Team Harness의 두 호스트 어댑터와 L5 agent-in-the-loop 시뮬레이션 테스트 비교

작성일: 2026-07-09 plugin: harness-aijient-team v0.10.0 baseline SHA: 990d07b task: codex-l5-sim-plan

핵심 결론

Claude 플러그인과 Codex 플러그인은 같은 harness-team CLI, 같은 AGENTS.md 계약, 같은 템플릿을 공유한다. 차이는 하네스를 호출하는 호스트 표면이다.

Claude 쪽은 slash command와 Claude hook/transcript 계약을 검증한다. Codex 쪽은 skill activation과 codex exec --json JSONL 이벤트 계약을 검증한다.

공유 불변식

실행 코어bin/, src/, templates/
프로젝트 SSOTAGENTS.md, task 4파일, .harness/active.json
판정 원칙파일, git, transcript, JSONL, hook output 증거만 PASS
산문 응답diagnostic only, PASS 신호로 사용하지 않음

플러그인 표면 비교

항목 Claude Code Plugin Codex Plugin
Manifest .claude-plugin/plugin.json .codex-plugin/plugin.json
주 진입점 commands/*.md slash commands skills/harness-team/SKILL.md 및 bundled skills
사용자 호출 /harness-aijient-team:harness-apply, /harness-task $harness-aijient-team:harness-team, 자연어 skill trigger
Headless 엔진 claude -p --output-format json codex exec --json --ephemeral
Transcript ~/.claude/projects/.../<session_id>.jsonl stdout JSONL event stream, thread.started, item.completed, turn.completed
Hook 신호 SessionStart nudge와 post-commit handoff를 직접 채점 post-commit compatibility는 채점, Claude SessionStart는 N/A
권한 모델 scoped allowed tools: node, git, harness-team, file tools probe는 workspace-write, full run은 throwaway에서 danger-full-access
대표 리스크 nested auth/token, slash namespace, transcript lookup sandbox가 .git/hooks 쓰기를 막는지, skill trigger가 의도대로 선택되는지

운영 판단

언제 Claude L5를 보는가

Claude slash command, Claude transcript, SessionStart hook, Claude Code 권한 allowlist가 깨졌는지 확인할 때 사용한다.

언제 Codex L5를 보는가

Codex plugin manifest, skill activation, codex exec --json 이벤트, Codex sandbox 정책과 설치된 hook compatibility를 확인할 때 사용한다.
