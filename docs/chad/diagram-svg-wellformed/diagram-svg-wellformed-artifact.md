- P3-3 속성 이름의 따옴표 제외를 고정하는 테스트 없음 — 진짜(코드 대조). 조치: 표본 `<rect a"b="1"/>` 추가 — 이름에 따옴표를 허용하는 변이로 실패 확인.
- P3-4 이벤트 핸들러 규칙이 좁아짐 — **진짜**. `a&#34;b="1" onclick=`·`a&#60;1="2" onclick=`를 옛 코드는 거부, 새 코드는 `[]`. 둘 다 not well-formed라 그려지지 않고 brief는 `<img>`로 싣는다 — 실행 경로 없음. 기존 결함 `aria-label="say &#34;hi&#34;" onclick=`(옛·새 모두 통과)도 재현. 후속 후보(이번에 안 함, 사용자 선택): 이벤트 핸들러 규칙만 원문에 돌리기.
