# th-whatschanged-upkeep — Artifact

*최종 결과물과 학습 내용을 기록한다.*

## 결과

- `MAINTAINING.md`에 release 도구 실행 직후 최신 변경 설명 문서 갱신, 같은 버전의 스냅샷 작성, `npm test`·`docs:generate`·`docs:check` 실행 단계를 추가했다.
- 기존 관례와 일관되게 `latest + 버전별 스냅샷`을 채택했고, 현재 `0.12.0` 스냅샷을 추가했다. 최신 문서는 README에서 접근할 수 있다.
- `tests/what-changes-latest-version.test.mjs`가 최신 문서의 제목·요약 버전, 현재 버전 스냅샷, 파일 완전 일치를 검사한다.
- 의도적으로 제목을 `${version}-stale`로 어긋나게 한 입력은 같은 테스트에서 assertion failure가 나는 것을 확인했다.
- 결정 근거와 재고 조건은 `MAINTAINING.md`의 `최신 변경 설명 문서의 최신성 보장`에 기록했다.

## Learnings

- `latest`라는 파일명은 절차상 갱신 단계와 그 결과를 확인하는 검사가 함께 있어야 신뢰할 수 있다. 역사 보존은 동일 내용의 버전별 스냅샷으로 해결하되, 변경 근거의 작성은 자동화하지 않는다.
