# th-whatschanged-upkeep — Spec

## 목적 / 요구사항

- `what-changes-latest-version.html`이 현재 `package.json` 버전을 설명하도록 릴리스 절차와 자동 검사를 보강한다.
- 변경 근거는 사람이 직접 작성하며, 외부 의존성이나 릴리스 도구 변경은 하지 않는다.
- 기존 `latest + 버전별 스냅샷` 관례와 문서 접근성을 함께 검토한다.

## 설계 / 접근

- 릴리스 도구가 버전을 bump한 직후 최신 문서 갱신·동일 버전 스냅샷 작성·검증을 절차에 둔다.
- Node 내장 `node:test`로 제목, 요약 버전, 스냅샷 존재와 최신 파일의 완전 일치를 검사한다.
- README에서 최신 변경 설명 문서로 연결한다.

## Ontology
*이 task가 다루는 핵심 개념의 정의. "X가 정확히 뭔가?"에 답한다.*

- **최신 변경 설명 문서**: 현재 `package.json` 버전의 변경과 사람이 검토한 근거를 설명하는 HTML이다.
- **버전별 스냅샷**: 해당 버전 시점의 최신 변경 설명 문서와 바이트 단위로 같은 역사 기록이다.
