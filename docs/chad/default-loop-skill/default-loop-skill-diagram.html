/harness-loop — plan 한 단계가 도는 길

메인 세션이 오케스트레이터다. Dev가 한 단계를 구현하면 오케스트레이터가 기계 검사(exit code)를 돌리고, 모든 단계가 끝나면 시나리오 전체를 제외 없이 다시 검사하고, 그 뒤에만 read-only 별도 프로세스가 루브릭(R2)과 R3를 판정한다. 검은 칩이 사람에게 넘기는 네 멈춤이다.
