DONE-DERIVE · STATE MACHINE + BEFORE/AFTER

머지가 곧 종결 — 기록하지 않고 계산한다

종결은 기본 브랜치 ref에서 plan이 전부 [x]인지로 계산한다. done은 가드를 검증할 뿐 추적 파일을 쓰지 않는다 (예외: --force 감사 흔적). 그래서 머지 뒤에 할 일이 없고, 종결 커밋과 보호 브랜치의 종결 MR이 사라진다.

종결 절차 — 지금과 이후

판정 · R1

closed ⇔ 셋 중 하나

  • 기본 브랜치 plan: 미완 - [ ] 없음 + [x] ≥ 1
  • 유효한 우회 기록: forcedAt > reopenedAt
  • 레거시 meta status: done

강제 지점 · R7

pre-push에서만 가드

  • plan이 전부 체크된 task에 collectDoneIssues
  • HEAD·깨끗한 트리일 때만, CI는 문서 검사만

주의

다중 MR task

  • 이후 단계를 plan에 미리 적어 둔다
  • 재개 전 기본 브랜치를 fetch
