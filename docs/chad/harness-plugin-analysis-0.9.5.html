3. 플러그인 개요

Claude 리드 + Codex/Gemini 리뷰어 + Cursor/OpenCode 보조 — 단일 소스(SSOT) 배선 도구

축 1 — 설정 스캐폴딩

  • AGENTS.md를 SSOT로, CLAUDE.md/GEMINI.md는 @AGENTS.md import 얇은 파일
  • .claude/rules ↔ .cursor/rules(.mdc) 미러링
  • .opencode/opencode.json — rules 자동 로드 + 스킬 3종 커맨드
  • 마크다운은 harness:section 마커 구간만 교체(비파괴 merge), JSON은 deep-merge

축 2 — task 라이프사이클

  • docs/<user>/<name>/에 spec·plan·handoff·artifact 4파일 SSOT
  • post-commit hook → handoff 자동 갱신 (src/git-hooks.mjs)
  • SessionStart hook → 활성 task 주입 (nudge, 비차단)
  • done-guard: 미완료 plan · 템플릿 artifact · 미커밋 변경 · 커밋 0건이면 완료 차단 (task.mjs:310-371)

부가 자산

  • symlink 백업 아키텍처 (clone.sh / symlink.sh / delete.sh)
  • 페르소나 커맨드: interview · contrarian · simplifier
  • 릴리즈 자동화: 3-manifest 동시 bump + 캐시 동기화
  • L4/L5 시뮬레이션 스킬 (harness-sim, SC1~SC6)

5. 장점

① 외부 의존성 0

Node 18+ stdlib만 사용. package.json에 dependencies 없음, 소스에 network fetch 없음 — 공급망 리스크 부재 (확인됨).

② 파괴적 작업 가드 실재

rm -rf는 4곳뿐 — 전부 확인 프롬프트 + byte-identity 검사(diff -rq/cmp -s) 또는 --include-real 명시 opt-in 뒤에만 실행. release는 --dry-run + version 문자열 1회 등장 가드.

③ 테스트 충실도

unit은 mkdtemp 격리, e2e는 실 바이너리 spawn으로 git repo·post-commit hook까지 3개 스택(bare-node/next/rn)에서 검증. 사용자 디렉토리 비접촉.

④ 자체 dogfooding

플러그인이 자신의 task 워크플로우로 개발됨(완료 task 12개). 0.9.5의 done-guard 마찰 수정은 실사용에서 발견된 버그.

⑤ 비파괴 merge 설계

harness:section 마커 구간만 교체, harness:user 구간 보존, JSON deep-merge — 기존 프로젝트에 안전하게 적용 가능.

⑥ 마이그레이션 내장

구버전 구조(0.2.x→0.6→0.8) 자동 감지, 멱등 마이그레이션 4단계.

6. 단점 / 리스크

보안 — 전반적으로 낮음

  • post-commit hook이 PATH 상의 harness-team 실행 — PATH 하이재킹 시 코드 실행 벡터 (일반 git hook 수준). 실패는 || true로 silent
  • release가 프로젝트 밖 ~/.claude/plugins/ 직접 수정 — Claude Code 실행 중 race condition 가능 (MAINTAINING.md도 경고)
  • repo의 settings.local.json 광범위 allowlist는 .gitignore로 배포 제외 — 소비자 비전파 (확인됨)

안정성 — 중간

  • symlink 아키텍처: 백업 디렉토리 삭제·이동 시(특히 iCloud) 프로젝트 설정 일괄 파손 — iCloud eviction 조합 미검증
  • pre-commit-check.sh의 pnpm 하드코딩 — npm/yarn 프로젝트에서 실패 또는 무의미
  • 0.9.0→0.9.5 2주 내 5회 릴리즈 — 활발하지만 아직 수렴 중

유지보수 — 중간

  • 버스 팩터 1 (단일 개발자)
  • CI 없음 (.github/workflows/ 부재), lint/typecheck 미설정
  • LICENSE 파일 없음 (package.json MIT 선언만)
  • 새 커맨드 추가 시 4개 파일 수동 동기화 (commands/·bin·plugin.json·README)
  • marketplace의 bd-makers/team-harness 원격 실존 미확인

조건부 도입 권장
