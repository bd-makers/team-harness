Fixed · CLI

명령 이름으로 새 task를 만들지 않음

이전
task list·task done·task handoff가 ^[\w.-]+$를 통과해 그 이름의 task 스캐폴드 6파일을 만들고 .harness/active.json을 옮겼습니다. 되돌리려면 삭제가 필요했습니다.
지금
새로 만들 이름이 COMMANDS의 명령 이름(27개)이면 exit 1로 멈추고 아무것도 쓰지 않습니다. harness-team <name>을 뜻했는지 안내하는 5필드 에러 패킷을 냅니다(--json 동일).
호환
그 이름의 task(<name>-spec.md 마커)가 이미 있으면 종전대로 활성화합니다. 예약어는 명령 표 단일 소스라 명령이 늘면 따라옵니다.
