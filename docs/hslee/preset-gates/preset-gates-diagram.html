Architecture · preset-gates plan

언어 지식은 프리셋에, 훅은 확정된 목록만 실행한다

사라지는 것 (D11)

훅 안의 언어 지식

  • pre-commit-check.sh의 lockfile → PM 추론(pnpm·yarn·bun·npm)과 tsc·test 분기
  • auto-format.sh의 확장자 분기 + 하드코딩 npx prettier --write
  • PM별 실행 형태는 프리셋 JSON의 pm 표로 이동

경계 동작

실패 의미

  • 명령 실패 → 차단(exit 2), 127 → 설정 오류로 차단
  • gates 없음 → 통과 + 미설정 안내
  • CLI 없음 → commit은 경고 후 통과, format은 조용히 통과

덮지 않는 것 (D8)

확정값 보존

  • 이미 있는 gates — init·migrate는 건너뜀
  • 커스터마이즈 훅 — migrate가 제안하지 않음
  • 덮어쓰기는 gate suggest 확인 후뿐
