## Learnings
- **강의 저장소 README와 강의 02의 5분류가 다르다.** README 본문은 지시·상태·검증·범위·세션 수명주기, 강의 02·harness-designs는 지시·도구·환경·상태·피드백이다.
  요약 도구(WebFetch)만 읽었다면 "도구·피드백 하위 시스템은 없다"는 틀린 결론으로 갔다 — 원문 마크다운을 커밋 고정으로 받아 대조한다.
- **착수 브리프의 수치도 실측으로 다시 잰다.** eager 여유는 "약 150 B"가 아니라 233 B였다. `MAINTAINING.md:52`의 1,075 B는 더 낡았다 — 문서에 박은 측정값은
  다음 커밋부터 틀리기 시작한다(후보 D).
- **소비자 대조 전에 설치 버전부터 본다.** gates가 없는 소비자 2곳은 gates(0.46.0) 이전 버전이라, 그대로 "피드백 빈틈"으로 쓰면 틀린 근거가 된다.
- **규범만으로 지키는 상태는 측정해야 보인다.** TCC 미작성은 리뷰가 세 번 잡은 개별 사례였지만, 전수로 재니 29%였다.
