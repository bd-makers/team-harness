member 이름의 경로 탈출

이전
{"user":"../../x"}인 checkout에서 task foo를 실행하면 task 파일 6개가 프로젝트 root 밖 <root>/../x/foo/에 생기고 .harness/active.json이 그곳을 가리켰습니다.
지금
결정된 member가 비어 있거나 /·\를 포함하거나 .으로 시작하거나 제어문자가 있으면 task가 exit 1로 멈추고 아무것도 쓰지 않습니다. config·--member·폴백 어느 출처든 같은 규칙이라 손으로 고친 config와 config set user도 막힙니다.
허용
문자 집합은 제한하지 않습니다 — 한글·공백 이름(Chad Lee)과 a..b는 종전대로 통과합니다.
