4Done evidencespec에 선언

{ "version": 1, "tests": "required", "review": "optional", "verify": "optional" }
tests기본 required — 소스가 바뀌었으면 테스트 파일 변경도 요구
review기본 optional — required면 판정 창 안의 리뷰 마커 요구 (kind 무관)
verify기본 optional — 검증 프레이밍 kind만 인정

검증 마커는 review를 겸하지만 역은 아니다

✕하지 말 것전부 실제 사고 사례

  • ✕안 끝난 단계를 - [x]로 켜기 — 체크박스는 done 가드와 세션 재개 판정이 읽는다
  • ✕spec을 외부 문서 포인터 껍데기로 두기 — 자가진단 없는 spec은 doctor가 경고
  • ✕같은 브랜치·워킹트리에서 병렬로 쓰기(D4) — 격리하려면 worktree(D5). 읽기·반박 병렬은 자유
  • ✕리뷰를 돌리고 기록 안 남기기 — 남기지 않은 리뷰는 “안 한 것”
  • ✕집계 파일 손으로 고치기 — task_summary.md·<user>-task.md는 생성물
  • ✕다이어그램 체크박스 지우기 — 못 했으면 지우지 말고 사유를 붙여 닫는다
  • ✕개인 메모리에 팀 학습 넣기 — 다른 팀원·리뷰 엔진에게 안 보인다
