01 / 03 · 재지 않은 것은 보이지 않는다

점검이 초록불을 켜는데, 실제로 매 세션 로드되는 지시는 이미 예산을 넘어 있었다.

  • 화면harness-team doctor 리포트 · eager tier size 항목
  • 제품하네스 무결성 점검 · eager 계층 예산
  • 소스src/commands/doctor.mjs · checkEagerTierSize

이전 문제

예산은 24 KiB인데 세는 대상이 프로젝트 AGENTS.md·CLAUDE.md 둘뿐이었다. 같은 계층인 프로젝트 .claude/CLAUDE.md와 사용자 전역 CLAUDE.md가 빠져, 합계가 예산을 넘어도 점검은 통과라고 답했다.

개선

매 세션 무조건 로드되는 네 곳을 모두 더해 합계 하나로 판정한다. 파일마다 임계를 두면 "각 파일은 통과, 합계는 초과"가 그대로 빠져나가기 때문이다. 여전히 경고이지 실패가 아니다.

변경 후

02 / 03 · 경고가 가리키는 방향

경고를 읽은 사람이 정작 용량을 차지하지 않은 파일부터 뒤지게 되어 있었다.

  • 화면doctor 경고 문구 · ⚠️ eager 계층 …
  • 제품점검 결과 처방 · 소유 경계 안내
  • 소스src/commands/doctor.mjs · 경고 메시지 조립부

이전 문제

합계 숫자 하나와 고정된 처방 한 줄만 나왔다. 용량의 대부분이 사용자 전역 파일에서 왔더라도 "프로젝트 파일의 절차를 옮기라"는 안내가 먼저 나와, 초과를 만들지 않은 파일로 사람을 보냈다.

개선

파일별 바이트와 전역 파일의 해결된 실제 경로를 함께 보여 주고, 처방은 많이 차지한 계층부터 말한다. 전역 파일에는 지시 대신 사실만 알린다 — 하네스는 그 파일을 읽기만 한다.

변경 전

변경 후

유저 체감 · 경고를 읽자마자 어느 파일을 열어야 하는지 알고, 손대면 안 되는 파일은 손대라고 하지 않는다

03 / 03 · 리뷰가 막아 세운 것

측정 범위를 넓히자 테스트가 개발자 개인 홈 파일에 물려, CI만 초록이고 각자 노트북에서만 빨개질 뻔했다.

  • 화면로컬 npm test 출력 · PR 체크
  • 제품테스트 신뢰성 · 샌드박스 격리
  • 소스tests/e2e/sandbox.mjs · tests/sim/agentloop.mjs · codex-agentloop.mjs

이전 문제

e2e·시뮬레이션 스위트가 doctor의 성공을 단언하는데, 그 판정이 이제 저장소 밖 파일의 크기에 좌우됐다. 20 KiB짜리 개인 전역 파일로 재현하니 3건 전부 실패했고, CI에는 그 파일이 없어 초록으로 남았다.

개선

샌드박스가 만드는 환경에 설정 홈 경로를 고정한다. 이미 같은 이유로 플러그인 경로를 고정하던 선례를 따랐고, 같은 재현 절차가 이제 3건 모두 통과한다.

변경 전

변경 후

유저 체감 · 팀원 아무나 받아서 돌려도 테스트 결과가 같다 — 내 홈 디렉터리가 남의 빌드를 흔들지 않는다
