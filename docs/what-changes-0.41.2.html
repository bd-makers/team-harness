고친 것

Fixed · CLI

artifact 템플릿의 EOF 빈 줄

이전
새 artifact가 ## Learnings 다음 빈 줄로 끝나, task <name> 직후 커밋에서 git diff --check가 경고했습니다. retro가 붙이는 ## Learnings (<date>) 앞에는 빈 줄이 둘 생겼습니다.
지금
템플릿이 개행 하나로 끝납니다. retro 절 앞의 빈 줄도 하나입니다. spec·plan·artifact·context 템플릿 모두 EOF 빈 줄이 없음을 테스트가 지킵니다.
호환
done 가드의 "artifact가 템플릿 그대로" 판정은 앞뒤 공백을 무시하고 비교하므로, 옛 템플릿으로 만든 artifact도 종전대로 판정됩니다.
