Fixed · #202

tests 증거 기본값

전
기본 required — 선언하지 않아도 소스를 고치고 테스트 파일을 안 고치면 done이 막힌다.
후
기본 optional(0.52.0), skip은 같은 뜻. required를 선언할 때만 소스 변경과 테스트 파일 변경을 대조합니다. playground 시뮬레이터도 초기값이 optional이고 선택지에 넣었습니다.
Fixed · #202
